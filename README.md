# AUTONOMOUS AI AGENT 0.2.0 — Voice Edition

Android-проект для голосового помощника/агента на Galaxy Tab S8 и других Android-устройствах.

## Уже работает

- Голосовой ввод через Android SpeechRecognizer.
- Озвучивание ответов через Android TextToSpeech.
- Предпочтение русскоязычного женского TTS-голоса, если установленный TTS-движок помечает такой голос.
- Кнопка STOP.
- Accessibility Service.
- Действия: Назад, Домой, прокрутка, нажатие по тексту, ввод текста.
- Открытие системных настроек.
- Архитектура для будущей LLM: goal → snapshot → next action → execute → observe.
- LlmPlanner как точка подключения облачной/локальной модели.

## Примеры голосовых команд

- «Открой настройки»
- «Назад»
- «Домой»
- «Прокрути вниз»
- «Прокрути вверх»
- «Нажми Wi‑Fi»
- «Введи Бишкек»
- «Стоп»

## Важно о женском голосе

Android `TextToSpeech` не имеет универсального параметра "female".
Доступные голоса зависят от TTS-движка Samsung/Google и установленных языковых пакетов.
Проект предпочитает русскоязычный голос с female/woman/fem-маркером в имени, если он существует.
Иначе используется первый доступный русский голос.

На Galaxy Tab можно изменить TTS-голос в системных настройках синтеза речи.

## Сборка

1. Установите Android Studio.
2. Откройте эту папку как проект.
3. Дождитесь Gradle Sync.
4. Если Android Studio предложит установить Android SDK 35 — согласитесь.
5. Подключите Galaxy Tab S8 с USB debugging.
6. Нажмите Run.
7. Для APK:
   `Build → Build Bundle(s) / APK(s) → Build APK(s)`.

Debug APK:
`app/build/outputs/apk/debug/app-debug.apk`

## После установки

1. Запустите AUTONOMOUS.
2. Разрешите микрофон.
3. Нажмите «Включить доступ к экрану Android».
4. В списке Accessibility найдите AUTONOMOUS и включите.
5. Вернитесь в приложение.
6. Нажмите «Говорить» и произнесите команду.

## Что пока НЕ включено

Версия 0.2.0 намеренно не содержит API-ключ внутри APK и не отправляет экран произвольной LLM.
`LlmPlanner.kt` — безопасная точка интеграции.

Следующая версия может добавить:
- реальный LLM Planner;
- цикл Plan → Act → Observe → Verify;
- wake word;
- голосовой диалог без нажатия кнопки;
- подтверждение чувствительных действий;
- локальную модель или защищённый сервер-посредник.

## Безопасность

Не храните секретный API-ключ прямо в исходниках Android-приложения или APK.
Для облачной LLM лучше использовать свой backend/proxy с аутентификацией и лимитами.
